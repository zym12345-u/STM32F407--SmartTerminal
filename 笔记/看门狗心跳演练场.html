/* IWDG_Init(): KR=0xCCCC 启动, RLR=125, 窗口约 1.0s */
喂一次狗（写 0xAAAA）计数器装回 125；没人喂就数到 0，整板复位
counter = 125 / 125 正常运行
判死公式的三个参数
now 系统 tick（秒），点「时间 +0.5s」前进 0.0s
s_lastBeat[i] 各任务最后心跳时间戳，只在 Watchdog_Heartbeat() 里被覆盖 见格子
counter IWDG 硬件递减计数器，巡查通过才装回 RLR=125 125
判死: (now − s_lastBeat[i]) > 3s → CheckAllAlive 返回 0，不喂狗
复习路径：①先看参数区认清 now / s_lastBeat / counter 是谁；②「报心跳 → 巡查 → 时间+0.5s」循环几次，感受正常节奏（巡查通过 counter 回满 125）；③按「WIFI 卡死」后只点报心跳和时间，看 WIFI 格子年龄涨破 3s 变红；④再点巡查会显示「不喂狗」，继续点时间看 counter 数到 0 整板复位。最后想：挂的是 WIFI 一个任务，为什么复位的是整块板子？
