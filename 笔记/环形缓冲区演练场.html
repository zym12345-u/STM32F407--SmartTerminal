环形缓冲区演练场
bsp_RS485.c 的 8 格缩影（真实是 256 格，逻辑逐行一致）
H head · ISR 写 T tail · 任务读 有效数据 = T 到 H 之间的格子
/* 空缓冲: s_rxTail == s_rxHead */
head 追 tail：相遇即空，差一格即满
count = (0 + 8 − 0) % 8 = 0 空
count 公式的三个参数
head 写指针（下一个要写入的坑位），仅 ISR 推进 0
tail 读指针（下一个要读出的坑位），仅任务推进 0
N 缓冲大小（演示 8，真实代码 RS485_RX_BUF_SIZE = 256） 8
count = (head + N − tail) % N
复习路径：①先看参数说明里 head/tail/N 是谁；②点「写 1 字节」观察 head 前进、count 增长；③点「读 1 字节」观察 tail 追 head；④连续写满验证"牺牲一格"的满判定；⑤RxFlush 就是把 tail 甩到 head。
