# 工业物联网边缘网关 V2.0
基于 STM32F407 + FreeRTOS + LVGL 开发工业级边缘网关，在 V1 版本基础上完成功能迭代，新增**Flash分区管理、系统日志、日志浏览、独立看门狗、故障自复位、低功耗息屏、MQTT自动重连**，具备传感器采集、本地可视化、云端上报、断网缓存&自动补传全链路能力，适配工业现场7×24小时无人值守场景。

## 软件架构
### FreeRTOS 任务划分
| 任务 | 优先级 | 栈大小 | 核心职责 |
|:---|:---:|:---|:---|
| UI任务 | AboveNormal | 1024 | LVGL界面刷新、页面跳转、息屏控制 |
| 传感器任务 | Normal+1 | 512 | Modbus多从机轮询采集 |
| MQTT任务 | Normal | 512 | 数据上报、离线缓存、自动补传 |
| 网络任务 | Normal | 512 | 心跳检测、自动重连 |
| 看门狗任务 | Highest | 512 | 定时喂狗，故障自复位 |

### 任务同步机制
- 消息队列：传递传感器数据、UI刷新指令
- 互斥锁：保护串口、Flash等共享资源，防止并发冲突
- 全局状态标志：标记网络在线/离线状态

## 核心功能（V1基础 + V2新增）
### 1. Modbus-RTU 协议（手写实现）
- 支持多从机轮询，适配温湿度、光照传感器，可灵活扩展设备；
- 实现**CRC16查表算法**，搭配双超时机制，保证总线通信稳定；
- 直接操作串口寄存器收发数据，规避HAL库阻塞问题。

### 2. MQTT 3.1.1 协议（手写裸协议）
- 手动封装连接、订阅、发布、心跳全套二进制报文，无第三方依赖；
- 基于ESP8266透传模式对接**巴法云MQTT平台**；
- 新增**心跳检测+自动重连**，网络异常自动恢复连接。

### 3. SPI Flash 分区管理（V2核心新增）
将8MB W25Q64划分为两个独立分区，各司其职：
1. **4MB 运行日志区**
   统一日志接口，分级记录设备运行、网络、异常事件；日志循环覆盖，LVGL页面**倒序查看**（新日志置顶）。
2. **4MB 离线缓存区**
   基于**环形缓冲区+魔术字**实现断电续写；断网自动存数据，重连后**分批自动补传**；数据上报后仅修改标记实现逻辑删除，减少Flash擦除损耗。

### 4. 独立看门狗 & 故障自愈（V2新增）
- 片内IWDG独立看门狗，溢出时间20s，高优先级任务3s定时喂狗；
- 系统卡死、任务死锁时**自动硬件复位**，满足工业7×24小时运行要求。

### 5. 低功耗智能息屏（V2新增）
- 设备10秒无数据/触摸动作，自动关闭LCD背光；
- 数据更新、触摸操作时自动亮屏，有效降低整机功耗。

### 6. LVGL 图形界面（V2新增日志页）
- 主界面：传感器数据、进度条、设备状态、运行时长实时展示；
- 新增**日志浏览页面**，支持页面切换、触摸交互；
- 自定义中文字体，控件按需刷新，优化CPU占用。

## 常见问题与解决方案
| 问题现象 | 解决方案 |
|:---|:---|
| Modbus数据异常 | 核对RS485 A/B线，增加终端电阻 |
| MQTT连接失败 | 重新核算报文长度，检查WiFi/平台配置 |
| 意外自动复位 | 提高喂狗任务优先级，保证正常喂狗 |
| 日志无显示 | 上电初始化日志写指针，校验魔术字 |
| 串口死锁 | 规范互斥锁使用，避免嵌套加锁 |
| 息屏无法唤醒 | 动作触发时重置空闲计时、点亮背光 |

## 快速使用
1. **硬件接线**：严格对照引脚表接线，所有模块共地，ESP8266独立供电；
2. **固件要求**：ESP8266烧录标准AT固件，STM32使用Keil/STM32CubeIDE编译烧录；
3. **平台配置**：注册巴法云，修改代码内WiFi信息、设备UID与主题；
4. **运行测试**：上电自动联网采集、上传数据；断网自动缓存，重连自动补传；点击日志按钮查看运行记录。
